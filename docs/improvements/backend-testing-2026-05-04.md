# [改善] backend/ テスト基盤の整備とカバレッジ目標設定

## 概要

`backend/` にテスト基盤を整備し、CI でカバレッジを計測・強制する仕組みを構築する。

## 背景

週次品質レポート（2026-05-04）において、テストスコアが 0/10（ランクD）と判定された。
現状、テストファイル（`*_test.go`）が一切存在しない。

参照: [週次品質レポート 2026-05-04](../scoring/backend-2026-05-04.md)

## 対応内容

- [ ] モック生成ツールの導入（`github.com/golang/mock/mockgen` 等）
- [ ] テーブル駆動テストのベストプラクティスをテンプレートとして整備
- [ ] CI パイプラインへの `go test -cover ./...` の追加
- [ ] カバレッジ閾値の設定（目標: 60%以上）
- [ ] テストヘルパー関数の整備（`backend/testutil/` 等）

## 受け入れ条件

- `go test ./...` が CI で実行される
- カバレッジレポートが生成される
- カバレッジが閾値を下回った場合に CI が失敗する

## 優先度

中（アーキテクチャ基盤構築後）
