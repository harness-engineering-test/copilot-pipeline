# [改善] backend/ セキュリティスキャン・脆弱性チェックの導入

## 概要

`backend/` のコードに対して自動セキュリティスキャンを設定し、脆弱性を継続的に検出できる体制を整える。

## 背景

週次品質レポート（2026-05-04）において、セキュリティスコアが 0/10（ランクD）と判定された。
現状、セキュリティチェックの仕組みが存在しない。

参照: [週次品質レポート 2026-05-04](../scoring/backend-2026-05-04.md)

## 対応内容

- [ ] `gosec` の CI への組み込み（Goセキュリティスキャン）
- [ ] `govulncheck` の導入（依存パッケージの脆弱性チェック）
- [ ] CodeQL による静的解析の有効化（GitHub Actions）
- [ ] シークレット管理のガイドライン策定（環境変数 / Secret Manager の利用方針）
- [ ] 認証・認可パターンのドキュメント化

## 受け入れ条件

- PR マージ前にセキュリティスキャンが自動実行される
- 高・クリティカルな脆弱性が検出された場合に CI が失敗する
- シークレットがコードにハードコードされない仕組みが整っている

## 優先度

高（実装開始と同時に設定）
